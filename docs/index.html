Running in minutes.

The installer includes everything it needs and doesn't ask for administrator rights.

  1. Install

    Run the installer. If Windows shows SmartScreen, choose More info, then Run anyway.

  2. Add the extension

    The Setup window shows how to load it in Chrome, Edge or Brave using Developer mode.

  3. Download

    Click a file, or press Download on a video. Progress opens on its own.

Questions.

Is it really free?

Yes. There's no trial, account or subscription, and the source code is available under the MIT license.

Which systems does it support?

Windows 10 version 1607 or later and Windows 11, on Intel, AMD and ARM processors. The extension works in Chrome, Edge and Brave.

Why does Windows warn me about the installer?

The installer isn't code-signed yet, so SmartScreen doesn't recognise it. You can read the source and check each file's SHA-256 on the releases page.

Why is the extension installed in Developer mode?

It isn't in the browser stores yet, so it's loaded from the app's folder. Your browser may show a reminder about Developer mode.

Can it download every video?

No. DRM-protected services and live streams aren't supported, and some sites may not work. Sites that need sign-in work best when Node.js is installed.

Does it collect my data?

The app has no accounts, ads or tracking. Your download list stays on your PC, and cookies are only used to fetch the file you asked for.
